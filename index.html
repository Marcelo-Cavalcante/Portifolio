Sobre

Quem constrói o que você está vendo

Sou desenvolvedor Full Stack, formado em Análise e Desenvolvimento de Sistemas, com foco em Front-end, em transição de carreira depois de anos atuando na área administrativa. Essa bagagem me ajuda a entender o problema antes de escrever código: quem vai usar a tela, o que precisa acontecer e onde o processo costuma travar.

No front-end trabalho com HTML semântico, CSS moderno e JavaScript para construir interfaces responsivas e acessíveis, também com React. No back-end, uso Node.js e SQL para dar suporte a essas interfaces com rotas, dados e integrações de API. Já publiquei seis projetos próprios, todos com código aberto no GitHub.

  • Tirar um negócio do "só tenho Instagram" para uma página própria, rápida e responsiva.
  • Transformar layouts e ideias em interfaces funcionais, do celular ao desktop.
  • Consumir APIs e exibir dados de forma clara, com tratamento de erro e carregamento.

  • Código legível

    HTML semântico e CSS organizado, fáceis de manter e evoluir.

  • Mobile-first

    O layout é pensado primeiro no celular e cresce até o desktop.

  • Performance e acesso

    Imagens otimizadas, poucas dependências e navegação por teclado funcionando.
